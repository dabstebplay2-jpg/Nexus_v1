# Аудит Nexus — 14 июля 2026

## Текущее состояние

Локальная версия Nexus готова для закрытого тестирования: сайт, Cloud API и IDE API запускаются одной командой, проходят health-check и работают на портах 5173, 8080 и 8000. Хостинг намеренно не входит в этот этап.

Проверено после последнего release-pass:

- Cloud API: 173 теста успешно.
- Frontend: production-сборка успешна, changelog проверяется автоматически.
- Ruff: изменённый серверный код без ошибок.
- `npm audit`: 0 известных production-уязвимостей во Frontend и Admin UI.
- Polza.ai: живой источник доступен, 382 модели получены, 297 распознаны как текстовые, 69 показаны пользователю, 40 новых добавлены автоматически.
- Каталог моделей сохраняется на диск и обновляется сервером раз в 24 часа.
- Новая таблица облачных пространств создана и включена в резервные снимки и полное удаление аккаунта.

## Что улучшено

### Интерфейс

- Добавлен единый современный каркас страниц, панелей, кнопок, пустых состояний и адаптивной вёрстки.
- Полностью переработаны Browser, Пространства, Артефакты, Тарифы, Коннекторы и юридические страницы.
- Улучшены настройки аккаунта, использование, платежи, подписка и поддержка.
- Тарифные карточки стали читаемее; тестовые промокоды скрыты в обычном режиме.
- Вкладки браузера получают понятные заголовки страниц.
- Внутренние названия серверов и переменных больше не показываются посетителям в сообщениях об ошибках.

### Функциональность

- Восстановлен вход по одноразовому коду из email, включая обновление сессии.
- Персональные Polza.ai-ключи создаются и восстанавливаются с корректным лимитом тарифа.
- Пространства и их диалоги синхронизируются с аккаунтом между устройствами; гостевые данные остаются локальными.
- Артефакты открываются, копируются и скачиваются полностью, без прежнего обрезания кода.
- IDE Web больше не использует системные `alert`, `prompt` и `confirm`; добавлены собственные диалоги с обработкой ошибок.
- Автоинструменты включены по умолчанию: модель сама выбирает веб-поиск, генерацию изображения или доступный коннектор.
- Явный поиск показывает ход работы даже при выключенном автоматическом режиме; поисковый планировщик поддерживает Polza.ai и OpenRouter.
- Запрос на создание изображения автоматически направляется в доступную image-модель.
- Исправлена индикация выполнения SQL и очистка старых диалогов сверх лимита.
- OpenRouter Free Router остаётся доступным как резерв, если настроен сам OpenRouter, но временно недоступен его каталог моделей.

### Надёжность данных

- Пространства изолированы по пользователям даже при одинаковом локальном идентификаторе.
- Удаления синхронизируются между устройствами.
- Резервный снимок обновлён до версии 5 и сохраняет пространства вместе с пользователями, чатами и платежными данными.
- Полное удаление аккаунта очищает новые связанные записи.

## Что нужно до публичного релиза

Эти пункты нельзя безопасно завершить без внешних кабинетов или решения владельца:

1. **Free-ИИ:** добавить `OPENROUTER_MANAGEMENT_API_KEY` или `OPENROUTER_API_KEY`, если бесплатный облачный чат должен входить в релиз. Без ключа платные тарифы Polza.ai работают, а Free-ИИ честно недоступен.
2. **Оплата:** добавить боевые данные магазина ЮKassa и провести реальную оплату, возврат и webhook в тестовом платеже.
3. **Дополнительный вход:** при необходимости настроить Google OAuth и Telegram-бота. Вход по email уже рабочий и не зависит от них.
4. **Коннекторы:** Gmail, GitHub и Vercel требуют отдельных OAuth-приложений и redirect URI.
5. **Дистрибутивы:** подписать Windows-сборки Browser/IDE сертификатом перед широкой раздачей.
6. **Финальная визуальная приёмка:** вручную пройти основные сценарии на телефоне и ПК после последней смены дизайна.

## Локальный запуск

```powershell
cd C:\Nexus_Ai_site
.\nexus.bat start
```

Открыть `http://localhost:5173`. Проверка состояния: `nexus.bat diagnose`, остановка: `nexus.bat stop`.
