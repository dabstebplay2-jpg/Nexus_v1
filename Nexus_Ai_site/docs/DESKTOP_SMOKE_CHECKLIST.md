# Nexus IDE Desktop — smoke checklist

Перед публикацией релиза `desktop-v*`.

## Установка

- [ ] ZIP распаковывается, приложение запускается без ошибок
- [ ] Иконка и имя «Nexus IDE» в заголовке окна
- [ ] OpenVSX: Extensions → поиск «Prettier» → Install

## Облако Nexus

- [ ] `nexus.cloudUrl` указывает на рабочий API (prod или staging)
- [ ] **Nexus: Sign In** — успешный вход
- [ ] Панель **Nexus → Account & Billing** показывает тариф / пул
- [ ] **Nexus → AI Chat** — список моделей загружается (не пустой для платного тарифа)
- [ ] Отправка сообщения — **стриминг** ответа (текст появляется по частям)
- [ ] После «привет» кнопка **Отправить** снова активна (не зависает «Стоп»), ответ виден в течение ~30 с
- [ ] В режиме **Агент** на «привет» нет лишних tool-call — только текстовый ответ
- [ ] **🌐 Поиск в сети** — вкл/выкл, глубина quick / standard / deep; при включённом поиске видны этапы (план → анализ → раунды)
- [ ] **Режим мышления** (GPT-5.4 / Kimi K2.6 и др. с `supports_thinking`) — переключатель под моделью; блок «Мышление и поиск» сворачивается после ответа
- [ ] Ответ с веб-поиском — кнопка **Источники (N)** раскрывает ссылки
- [ ] Dropdown **агента** (если на аккаунте есть агенты) — запрос уходит с выбранным `agent_id`
- [ ] **Режим агента** (кнопка в header) — «что в папке проекта?» вызывает `list_dir` / `read_file`, не выдумывает список
- [ ] Timeline **инструментов** (list_dir, read_file, write_file, terminal) виден над ответом
- [ ] **Мышление** отображается **над** ответом, не под ним; логотип Nexus в header
- [ ] После ответа баланс/профиль обновляется (**Nexus: Refresh Account Status**)

## Редактор и AI

- [ ] Открыт файл → в чате виден контекст (имя файла / выделение)
- [ ] **Nexus: Add Selection to AI Chat** добавляет выделение
- [ ] Ответ с блоком ` ```lang path/to/file ` → кнопка **Применить** вставляет в файл
- [ ] **Nexus: Apply Last AI Code Block** работает из палитры команд

## Workbench

- [ ] Терминал: **Terminal → New Terminal** — shell открывается
- [ ] Git: папка с репозиторием → Source Control показывает изменения
- [ ] Отладка: Run and Debug — конфигурация (хотя бы launch placeholder не ломает UI)
- [ ] Command Palette (**Ctrl+Shift+P**) — команды `Nexus:*` видны

## Регрессия

- [ ] Выход **Nexus: Sign Out** — чат просит войти снова
- [ ] Перезапуск IDE — сессия сохраняется (токен в SecretStorage)
