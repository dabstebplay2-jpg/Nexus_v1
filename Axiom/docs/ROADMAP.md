# Axiom Roadmap

## v0.1 — Chat foundation

Общий Core, типы мультимодальных сообщений, provider registry, Mock и OpenAI-compatible, локальный HTTP API, SQLite, Secret Storage, Chat UI с потоками/отменой/редактированием/повтором и настройками. Базовые автоматические проверки. Текущая версия.

## v0.2 — Files / multimodality / projects

Отдельное файловое хранилище вместо встроенных данных, безопасное извлечение PDF/Office, модель attachment lifecycle, проекты и группировка диалогов. Индивидуальный редактор capabilities, нативные Anthropic/Gemini, управление контекстным бюджетом. OS-backed Secret Storage, экспорт/резервное копирование и миграции. Доступность интерфейса и расширение браузерных тестов.

## v0.3 — Tools / Web / MCP

Tool registry, форматы вызова и результата, политики разрешений и подтверждения действий, провайдер web search, MCP adapters. UI показывает источники и выполняемые действия. Разделение предложения действия и его исполнения.

## v0.4 — Memory

Явная управляемая память с просмотром, редактированием и удалением. Раздельные области пользователя/проекта/диалога, аудит происхождения, опциональный retrieval. Без скрытого сохранения чувствительных данных.

## v0.5 — Agents / Router / Verifier

Модель задач и исполнения, маршрутизация по capabilities/стоимости/политикам, агентные роли, проверка результатов и управление отменой. Исполнение строится поверх Core, а не логики браузерного чата.

## v1.x — Axiom Code и Axiom CLI

Отдельное приложение Code с рабочими пространствами, инструментами кода, review и собственной архитектурой агентов. CLI для тех же use cases. Совместное использование Core, Providers, Storage и настроек. Изоляция исполнения, стабильный публичный API, переносимость и упаковка приложений.

Этапы описывают направление, а не уже реализованные функции. Каждый следующий этап должен сохранять независимость UI от поставщика модели и сопровождаться контрактными тестами.
