# NexusAI

Моя собственная языковая модель.

## Versions

### v0.001
Первый эксперимент.
Простая нейронная сеть.

### v0.006
Char level модель.
Генерация текста по символам.

### v0.008
Word level модель.
Переход от символов к словам.

### v0.009
Word Context Model.

Особенности:
- слова вместо символов
- контекст 2 токена
- генерация текста


### v0.010
Word Context 8 Model.

Особенности:
- контекст 8 токенов
- EOS token
- autoregressive generation
- universal loader support
