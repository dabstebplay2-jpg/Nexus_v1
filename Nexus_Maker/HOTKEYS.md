# Горячие клавиши Nexus Maker

| Клавиши | Действие |
|---|---|
| `V` | Выбор |
| `F` | Фрейм |
| `R` | Прямоугольник |
| `O` | Эллипс |
| `T` | Текст |
| `N` | Заметка |
| `P` | Перо в режиме рисования |
| `Shift+P` | Карандаш в режиме рисования |
| `B` | Кисть в режиме рисования |
| `Пробел` + перетаскивание | Перемещение холста |
| Колесо мыши | Масштабирование к курсору |
| `Shift` при создании | Сохранение пропорций |
| `Alt` при создании | Рисование из центра |
| `Alt` при выделении | Показ расстояний |
| `Ctrl+A` | Выбрать все доступные объекты |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить |
| `Ctrl+D` | Дублировать |
| `Ctrl+G` | Сгруппировать выделение |
| `Ctrl+Shift+G` | Разгруппировать |
| `Delete` / `Backspace` | Удалить |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Повторить |
| `[` / `]` | Опустить / поднять слой |
| `Ctrl+K` | Палитра действий |
| `Esc` | Закрыть окно, очистить выделение, вернуться к выбору |
