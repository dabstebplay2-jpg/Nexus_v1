# Nexus Maker 0.2

Nexus Maker — локальный визуальный редактор, объединяющий холст для интерфейсов, свободное рисование, анимацию, выдачу кода и автоматизируемый Editor API. Проект не использует облачные лимиты и сохраняет документ в браузере или в переносимом файле `.nexus`.

## Запуск

Понадобится актуальная версия Node.js.

```powershell
npm install
npm run dev
```

Откройте [http://127.0.0.1:5173/](http://127.0.0.1:5173/). В Windows также можно запустить `start.bat`.

## Проверка

```powershell
npm run test
npm run build
```

Тесты покрывают критическую математику координат, выделения, создания, изменения размеров и расстояний. Система координат проверяется при масштабе 25%, 50%, 100%, 200% и 400%.

## Основные возможности

- Холст с панорамированием, масштабированием к курсору, рамочным и множественным выделением.
- Иерархическая сцена с локальными координатами, вложенными поворотами, фреймами, группами, фигурами, текстом, изображениями и свободными контурами.
- Перемещение, изменение размеров, поворот, скругление, заливка, обводка, непрозрачность и тень.
- Дерево слоёв с вложенностью, порядком, видимостью, блокировкой и переименованием.
- Общая история Undo/Redo, копирование, вставка и дублирование.
- Магнитные направляющие и измерение расстояний по Alt.
- Режимы «Дизайн», «Прототип», «Рисование», «Анимация» и «Разработка».
- Локальные команды выравнивания, распределения, переименования и очистки.
- Реактивный автомакет (строка, колонка, сетка), constraints, fill/hug/percent, компоненты и экземпляры.
- Стили цвета/текста/эффектов и реактивные привязки переменных.
- Интерактивные прототипы с триггерами, переходами, возвратом и просмотром.
- Временная шкала и ключевые кадры.
- Генерация CSS, React и Tailwind.
- Импорт изображений, экспорт PNG/JPG/WebP/SVG, просмотр и файлы `.nexus`.

Полный перечень готового и ограничения версии находятся в [IMPLEMENTED.md](./IMPLEMENTED.md), горячие клавиши — в [HOTKEYS.md](./HOTKEYS.md), история — в [CHANGELOG.md](./CHANGELOG.md).

## Структура

```text
src/
  editor/
    api/          публичные команды документа
    document/     сохранение и загрузка
    export/       экспорт графики
    import/       импорт изображений
    viewport/     единая система координат
  components/     холст и интерфейс редактора
  lib/            геометрия и тесты
  store/          модель документа и история
  types/          типы редактора
```

## Формат проекта

Файл `.nexus` v3 — версионируемый JSON с объектами, порядком слоёв, переменными и стилями. Старые документы v1/v2 мигрируют автоматически. Автосохранение выполняется локально через localStorage; кнопка «Сохранить» создаёт переносимый файл.
